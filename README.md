# Discord Sender

Небольшая GUI-утилита на Python, которая автоматически отправляет сообщения из текстового файла в любое поле ввода: Discord, Telegram, чат Minecraft и т. д.

Для каждой строки скрипт копирует текст в буфер обмена, вставляет его через Ctrl+V и нажимает Enter.

## Возможности

- Простое окно на Tkinter в тёмной теме
- Сообщения берутся из `messages.txt`, по одному на строку (можно выбрать другой файл кнопкой «Обзор»)
- Пустые строки и строки, начинающиеся с `#`, игнорируются
- Настраиваемая задержка между сообщениями (от 0.05 до 30 секунд)
- Таймер до старта, чтобы успеть кликнуть в нужное поле ввода
- Лог отправки и кнопка «Стоп»
- Аварийная остановка: переместите мышь в левый верхний угол экрана (failsafe от pyautogui)

## Требования

- Windows (используется `ctypes.windll` и `keybd_event`)
- Python 3.9+

```bash
pip install pyautogui pyperclip
```

## Использование

1. Создайте рядом со скриптом файл `messages.txt` и впишите сообщения, по одному на строку:
   ```
   # это комментарий, он будет пропущен
   Привет!
   Второе сообщение
   ```
2. Запустите:
   ```bash
   python send_messages.py
   ```
3. Укажите задержку между сообщениями и время до старта.
4. Нажмите **Старт** и за время таймера кликните в поле ввода нужного чата.
5. Для остановки нажмите **Стоп** или уведите мышь в левый верхний угол.

## Как это работает

Текст вставляется из буфера, а не печатается по символам, поэтому поддерживаются кириллица, эмодзи и длинные строки. Ctrl+V отправляется через `keybd_event` из WinAPI, потому что такой способ обычно срабатывает в Discord там, где другие методы нет.

## Важно

Автоматическая отправка сообщений может нарушать правила платформ и серверов (в том числе ToS Discord и Telegram) и приводить к бану. Используйте скрипт только там, где это разрешено, например для тестов, своих серверов или с согласия администрации. Автор не несёт ответственности за последствия использования.
